The Mathematical Essence of Deep Neural Networks: From Composite Functions to Gradient Descent

Deconstructing the Core Formulas and Computational Flow of DNN Training Loop

Introduction

When we marvel at the amazing capabilities of artificial intelligence, we rarely think about the mathematical foundation behind it. In fact, the essence of Deep Neural Networks (DNN), mathematically, is an extremely complex composite function. It fits the mapping relationship between input data and output results through nested layers of simple linear transformations and non-linear activation functions.

To clearly demonstrate this process, we take the most basic Multi-Layer Perceptron (MLP, i.e., fully connected feedforward neural network) as an example, and deconstruct its core mathematical formulas according to the training loop of “Forward Propagation → Calculate Loss → Backpropagation and Update.”

1. Forward Propagation: The Flow of Data

Forward propagation is the process by which the neural network “makes predictions.” Data enters from the input layer, calculates layer by layer, and finally reaches the output layer.

1.1 Calculation of a Single Neuron

For the jjj-th neuron in layer lll, it receives the outputs a(l−1)a^{(l-1)}a(l−1) of all neurons in the previous layer (layer l−1l-1l−1) as input. Its calculation is divided into two steps:

Step 1: Linear Weighted Sum

zj(l)=∑iwji(l)ai(l−1)+bj(l)z_j^{(l)} = \sum_i w_{ji}^{(l)} a_i^{(l-1)} + b_j^{(l)}zj(l)​=i∑​wji(l)​ai(l−1)​+bj(l)​

Where:

  • wji(l)w_{ji}^{(l)}wji(l)​: The weight between the jjj-th neuron in layer lll and the iii-th neuron in layer l−1l-1l−1
  • bj(l)b_j^{(l)}bj(l)​: The bias of the jjj-th neuron in layer lll
  • zj(l)z_j^{(l)}zj(l)​: The net input before activation (Linear combination)

Step 2: Non-linear Activation

aj(l)=f(zj(l))a_j^{(l)} = f(z_j^{(l)})aj(l)​=f(zj(l)​)

Where:

  • fff: Activation function (such as ReLU: f(z)=max⁡(0,z)f(z) = \max(0, z)f(z)=max(0,z), or Sigmoid: f(z)=11+e−zf(z) = \frac{1}{1+e^{-z}}f(z)=1+e−z1​)
  • aj(l)a_j^{(l)}aj(l)​: The final output of this neuron, which will serve as input to the next layer

1.2 Matrix Form (Actual Calculation Method in Modern Deep Learning Frameworks)

In actual programming (such as PyTorch/TensorFlow), to improve computational efficiency, the calculation of one layer is converted into matrix multiplication. The overall calculation of layer lll is as follows:

Z(l)=W(l)A(l−1)+B(l)Z^{(l)} = W^{(l)} A^{(l-1)} + B^{(l)}Z(l)=W(l)A(l−1)+B(l)A(l)=f(Z(l))A^{(l)} = f(Z^{(l)})A(l)=f(Z(l))

Where:

  • A(l−1)A^{(l-1)}A(l−1): Output matrix of the previous layer (dimension: nl−1×mn_{l-1} \times mnl−1​×m, where mmm is batch size)
  • W(l)W^{(l)}W(l): Weight matrix of layer lll (dimension: nl×nl−1n_l \times n_{l-1}nl​×nl−1​)
  • B(l)B^{(l)}B(l): Bias matrix (dimension: nl×1n_l \times 1nl​×1, broadcast to mmm columns)
  • Z(l)Z^{(l)}Z(l) and A(l)A^{(l)}A(l): Net input and activated output matrices respectively

Boundary Conditions:

  • For the input layer: A(0)=XA^{(0)} = XA(0)=X (i.e., raw input data, such as feature vectors of poker cards)
  • For the output layer: A(L)=Y^A^{(L)} = \hat{Y}A(L)=Y^ (i.e., the final prediction value of the neural network, such as predicted win rate)

2. Loss Function: Measuring “How Wrong It Is”

After forward propagation produces the predicted value Y^\hat{Y}Y^, it needs to be compared with the true label YYY to calculate the error.

2.1 Mean Squared Error (MSE) - For Regression Tasks

In reinforcement learning (such as DouZero’s DMC algorithm), the network outputs continuous Q values, and MSE is typically used:

L(Y^,Y)=12m∑i=1m(y^(i)−y(i))2L(\hat{Y}, Y) = \frac{1}{2m} \sum_{i=1}^{m} (\hat{y}^{(i)} - y^{(i)})^2L(Y^,Y)=2m1​i=1∑m​(y^​(i)−y(i))2

Where:

  • mmm: Number of samples in the batch
  • y^(i)\hat{y}^{(i)}y^​(i): Predicted value of the iii-th sample
  • y(i)y^{(i)}y(i): True value of the iii-th sample (such as the true outcome GGG obtained from Monte Carlo simulation)

Note: The 12\frac{1}{2}21​ in front is to eliminate the coefficient 2 brought by the square when taking derivatives, making the formula more concise.

2.2 Cross-Entropy Loss - For Classification Tasks

If the network outputs probability distributions of various actions (such as AlphaGo’s policy network), cross-entropy is typically used:

L(Y^,Y)=−1m∑i=1m∑c=1Cyc(i)log⁡(y^c(i))L(\hat{Y}, Y) = -\frac{1}{m} \sum_{i=1}^{m} \sum_{c=1}^{C} y_c^{(i)} \log(\hat{y}_c^{(i)})L(Y^,Y)=−m1​i=1∑m​c=1∑C​yc(i)​log(y^​c(i)​)

Where:

  • CCC: Total number of categories (such as the number of legal action types in poker)
  • yc(i)y_c^{(i)}yc(i)​: One-hot encoding of the true label (1 if it’s the correct action, 0 otherwise)
  • y^c(i)\hat{y}_c^{(i)}y^​c(i)​: Probability of the ccc-th action predicted by the network

3. Backpropagation and Gradient Descent: How the Network Learns

This is the most core mathematical magic of DNN. The goal is to find the partial derivatives (gradients) of the loss function LLL with respect to every weight WWW and bias BBB in the network, then update parameters along the opposite direction of the gradient to minimize the loss LLL.

3.1 Chain Rule: Calculating Gradients

According to the chain rule in calculus, the partial derivative of loss LLL with respect to the weight W(l)W^{(l)}W(l) of layer lll can be decomposed into local partial derivatives multiplied continuously from the output layer all the way to layer lll:

∂L∂W(l)=∂L∂A(L)⋅∂A(L)∂Z(L)⋅∂Z(L)∂A(L−1)⋯∂A(l)∂Z(l)⋅∂Z(l)∂W(l)\frac{\partial L}{\partial W^{(l)}} = \frac{\partial L}{\partial A^{(L)}} \cdot \frac{\partial A^{(L)}}{\partial Z^{(L)}} \cdot \frac{\partial Z^{(L)}}{\partial A^{(L-1)}} \cdots \frac{\partial A^{(l)}}{\partial Z^{(l)}} \cdot \frac{\partial Z^{(l)}}{\partial W^{(l)}}∂W(l)∂L​=∂A(L)∂L​⋅∂Z(L)∂A(L)​⋅∂A(L−1)∂Z(L)​⋯∂Z(l)∂A(l)​⋅∂W(l)∂Z(l)​

This formula looks long, but in code implementation, it is efficiently calculated through dynamic programming (recursive from back to front).

Define Error Term (Delta)

δ(l)=∂L∂Z(l)\delta^{(l)} = \frac{\partial L}{\partial Z^{(l)}}δ(l)=∂Z(l)∂L​

This represents the impact of changes in the net input of layer lll on the final loss.

Then the gradient of weights can be expressed extremely concisely as:

∂L∂W(l)=δ(l)(A(l−1))T\frac{\partial L}{\partial W^{(l)}} = \delta^{(l)} (A^{(l-1)})^T∂W(l)∂L​=δ(l)(A(l−1))T∂L∂B(l)=δ(l)\frac{\partial L}{\partial B^{(l)}} = \delta^{(l)}∂B(l)∂L​=δ(l)

3.2 Gradient Descent Parameter Update

After calculating the gradients, use optimization algorithms (such as the basic SGD, or more advanced Adam) to update weights and biases:

W(l)←W(l)−α∂L∂W(l)W^{(l)} \leftarrow W^{(l)} - \alpha \frac{\partial L}{\partial W^{(l)}}W(l)←W(l)−α∂W(l)∂L​B(l)←B(l)−α∂L∂B(l)B^{(l)} \leftarrow B^{(l)} - \alpha \frac{\partial L}{\partial B^{(l)}}B(l)←B(l)−α∂B(l)∂L​

Where:

  • α\alphaα: Learning Rate. It determines the step size of each update. Too large may overshoot the minimum point (diverge), too small converges extremely slowly
  • ←\leftarrow←: Indicates replacing the old value with the newly calculated value

4. Summary: The Mathematical Closed Loop of DNN Training

Connecting the above formulas together, the complete mathematical flow of training a batch of data in a deep neural network is as follows:

  1. Input: Given data XXX and true labels YYY
  2. Forward: Calculate layer by layer through A(l)=f(W(l)A(l−1)+B(l))A^{(l)} = f(W^{(l)} A^{(l-1)} + B^{(l)})A(l)=f(W(l)A(l−1)+B(l)) to obtain predicted value Y^=A(L)\hat{Y} = A^{(L)}Y^=A(L)
  3. Calculate Loss: Calculate the gap between prediction and truth through L(Y^,Y)L(\hat{Y}, Y)L(Y^,Y)
  4. Backward: Use the chain rule to calculate ∂L∂W(l)\frac{\partial L}{\partial W^{(l)}}∂W(l)∂L​ and ∂L∂B(l)\frac{\partial L}{\partial B^{(l)}}∂B(l)∂L​ layer by layer from output layer to input layer
  5. Update: Update all parameters through W←W−α∇WLW \leftarrow W - \alpha \nabla_W LW←W−α∇W​L
  6. Loop: Repeat the above process tens of thousands of times (Epochs) until Loss converges to a minimum

Mapping in Poker AI (such as DouZero)

  • XXX is the current hand cards and play history features
  • Y^\hat{Y}Y^ is the Q value (win rate) predicted by the network for each action
  • YYY is the true win/loss result GGG obtained after completing a game through Monte Carlo simulation

Through this rigorous set of calculus formulas, the neural network continuously fine-tunes millions of internal weight parameters during tens of millions of self-play games, ultimately solidifying “poker intuition” into these matrix numbers.

5. Practical Application: DNN Mathematical Principles in the “Ding Ge Dan” Project

In the “Ding Ge Dan” AI dual-engine architecture, DNN’s mathematical mechanisms play a key role:

5.1 Construction of Feature Vectors

For the special rules of “3 cards as bomb, 4 cards as hun,” design specialized input vectors XXX to ensure the mathematical model can accurately capture these unique card pattern logics.

5.2 Selection of Loss Function

Since the DMC algorithm outputs continuous Q values (win rate predictions), Mean Squared Error (MSE) is used as the loss function to directly optimize the gap between predicted values and Monte Carlo true outcomes.

5.3 Learning Rate Tuning Strategy

Use larger learning rates in the early training stage for fast convergence, gradually reduce learning rates in later stages for fine-tuning, ensuring the model can both learn quickly and converge stably.

Introduce batch normalization technology in deep networks to solve the vanishing gradient problem and accelerate training convergence:
